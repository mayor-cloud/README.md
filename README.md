## What is Mayor Cloud?

**Mayor Cloud** is an ecosystem of cloud services and developer tools built to
help developers create, deploy, manage, and scale their projects.

### Services

- 🌐 **Web Hosting** — Deploy websites and applications.
- 🗄️ **Databases** — Managed databases for your projects.
- 🛠️ **Developer Tools** — Utilities for developers and creators.
- 🤖 **App Building** — Build and manage applications with Mayor Maker.
- ✉️ **Mail** — Email services across the Mayor ecosystem.
- ☁️ **Free Hosting** — Hosting for small projects and experiments.
- 👤 **Mayor Account** — One identity across Mayor Cloud.
- 📚 **Documentation** — Guides and resources for Mayor services.
