## What is Mayor Cloud?

**Mayor Cloud** is an ecosystem of cloud services and developer tools built to help
developers create, deploy, manage, and scale their projects.

### Services

- 🌐 **Hosting** — Deploy websites and applications.
- 🗄️ **Databases** — Managed databases for your projects.
- 🛠️ **Developer Tools** — Utilities for developers and creators.
- 🤖 **App Building** — Build and manage apps with Mayor tools.
- ✉️ **Mail** — Email services across the Mayor ecosystem.
- ☁️ **Cloud Infrastructure** — Scalable services for modern apps.
- 👤 **Account System** — One identity across Mayor products.
- 📚 **Documentation** — Guides and learning resources.
