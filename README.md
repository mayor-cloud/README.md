## What is Mayor Cloud?

**Mayor Cloud** is an ecosystem of cloud services and developer tools built to help developers create, deploy, manage, and scale their projects.

<br>

<table>
<tr>

<td width="50%">

### 🌐 Hosting

Deploy and manage websites and applications across the Mayor Cloud infrastructure.

</td>

<td width="50%">

### 🗄️ Databases

Managed database services built for modern applications and development workflows.

</td>

</tr>

<tr>

<td width="50%">

### 🛠️ Developer Tools

Utilities and tools designed to simplify everyday development tasks.

</td>

<td width="50%">

### 🤖 App Building

Create and manage applications using the Mayor ecosystem.

</td>

</tr>

<tr>

<td width="50%">

### ✉️ Mail

Email services integrated with Mayor Cloud accounts and applications.

</td>

<td width="50%">

### ☁️ Cloud Infrastructure

Infrastructure and services for deploying and running modern projects.

</td>

</tr>

<tr>

<td width="50%">

### 👤 Mayor Account

One centralized Mayor identity across supported Mayor Cloud platforms.

</td>

<td width="50%">

### 📚 Documentation

Guides, references, and resources for Mayor Cloud products and developers.

</td>

</tr>
</table>
