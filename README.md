## Welcome

Welcome to the official **Mayor Cloud Community** repository.

This repository hosts the organization-wide discussions for Mayor Cloud and serves as a central place for our community to ask questions, share ideas, request features, and follow project updates.

## Discussions

Use [GitHub Discussions](https://github.com/orgs/mayor-cloud/discussions) for:

- 💡 Ideas and feature suggestions
- ❓ Questions and support
- 📢 Mayor Cloud announcements
- 🛠️ Developer discussions
- 🌐 Open-source project discussions
- 💬 General community conversations

## Open Source

Mayor Cloud develops and maintains open-source projects, developer tools, libraries, bots, templates, and other resources.

You can explore our projects from the [Mayor Cloud GitHub organization](https://github.com/mayor-cloud).

## Community Guidelines

Please keep discussions:

- Respectful and constructive
- Relevant to Mayor Cloud or its projects
- Free from spam and abuse
- Safe for the wider developer community

When reporting a problem with a specific project, please use that project's **Issues** section whenever possible.

## Security

Please do **not** publish passwords, API keys, access tokens, private infrastructure information, or security vulnerabilities in public discussions.

Security-sensitive reports should be submitted privately through the appropriate Mayor Cloud security channel.
