## What is Mayor Cloud?

**Mayor Cloud** is an ecosystem of cloud services and developer tools designed
for building, hosting, managing, and scaling projects.

Our ecosystem includes:

- 🌐 **Web Hosting** — Deploy and host websites and applications.
- 🗄️ **Databases** — Managed database services for your projects.
- 🛠️ **Developer Tools** — Useful utilities for developers and creators.
- 🤖 **App Building** — Build and manage applications with Mayor Maker.
- ✉️ **Mail** — Email services powered by the Mayor ecosystem.
- ☁️ **Free Hosting** — Simple hosting for smaller projects and experiments.
- 👤 **Mayor Account** — One account across Mayor Cloud services.
- 📚 **Documentation** — Guides and resources for Mayor products.
